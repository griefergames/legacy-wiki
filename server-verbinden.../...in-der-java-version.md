# ...in der Java-Version

So fügt ihr GrieferGames in der Java-Edition zu eurer Serverliste hinzu und verbindet euch mit dem Netzwerk.

### Mehrspieler-Modus auswählen

Startet Minecraft und wählt im Hauptmenü den Mehrspieler-Modus aus.

<figure><img src="../.gitbook/assets/java_multiplayer.png" alt="Minecraft-Hauptmenü mit dem Button Mehrspieler"><figcaption><p>Den Mehrspieler-Modus auswählen</p></figcaption></figure>

Nach Auswahl des Mehrspieler-Modus geht ihr unter der Liste auf den Button "Server hinzufügen".

### Server-Angaben hinterlegen

Gebt einen beliebigen Servernamen (z. B. GrieferGames) und die folgende Serveradresse ein:

* Serveradresse: `griefergames.net`

<figure><img src="../.gitbook/assets/java_server_data.png" alt="Fenster Serverinformationen bearbeiten mit Servername und Serveradresse"><figcaption><p>Tragt die Daten ein und klickt auf "Fertig"</p></figcaption></figure>

### Verbindung herstellen

Der Server erscheint jetzt in eurer Serverliste. Wählt ihn aus und klickt auf "Server beitreten".

<figure><img src="../.gitbook/assets/java_server_use.png" alt="Serverliste mit GrieferGames und dem Button Server beitreten"><figcaption><p>Server in Liste auswählen und "Server beitreten" anklicken</p></figcaption></figure>
