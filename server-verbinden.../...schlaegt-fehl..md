# ...schlägt fehl.

### Unterstützte Versionen

Wir unterstützen das Verbinden mit Minecraft-Clients in den Versionen **1.8.x, 1.12.x, 1.16.x, 1.18.x, 1.19.x und 1.20.x** – Wir empfehlen zum fehlerfreien Spielen die Version **1.8.9** zu verwenden.

* Minecraft Launcher starten
* Auswahl "Installationen"
* Auswahl "Neu"
* Name vergeben
* Spielversion auswählen (siehe oben)
* Button "Speichern" drücken
* Auswahl "Spielen"
* Dropdown-Box in der unteren linken Ecke auswählen und das ausgewählte Profil anklicken
* Button "Spielen"

Neue Spielversionen werden von uns schnellstmöglich nach Release durch Microsoft freigegeben. Dies kann unter Umständen einige Stunden bis Tage dauern. Den aktuellen Stand zu Updates erfahrt ihr auf unserem Discord-Server.

Beta-Versionen der Bedrock Edition und Entwicklungs-Versionen der Java Edition werden von uns **nicht** unterstützt.&#x20;

### Server überlastet

Normalerweise verwenden wir die Adresse `griefergames.net` zum Verbinden. In Einzelfällen kann es sein, dass dieser Zugang überlastet ist. Versucht in diesem Fall eine alternative Adresse:

* alt.griefergames.net
* team.griefergames.net
* bungee1.griefergames.net

### Zu viele Verbindungen

Spielen viele Leute gleichzeitig bei euch über ein Netzwerk _(z.B. Familie, Schule, Wohnheim, etc.)_?\
Aus Sicherheitsgründen limitieren wir die Anzahl an Verbindungen pro IP-Adresse. Betroffene Nutzer können mit einem VPN einen anderen Access-Server auswählen. Ist dies nicht möglich, wendet euch bitte an ein Teammitglied aus dem Support.

### Modifikationen

Einige Modifikationen (bspw. LabyMod, OptFine, etc.) sind ggf. nicht für die Server-Version ausgelegt oder selbst nicht auf aktuellem Stand. Versucht in solch einem Fall einmal mit einer Installation ohne Modifikation zu verbinden.

### Firewall-Einstellungen

Minecraft verwendet für die Verbindung den Port `25565` über TCP und UDP. Die Bedrock-Version verwendet zum Verbinden den Port `19132` oder `19134`. \
Bitte prüfe in deiner Firewall, deinem Router und ggf. deiner Sicherheitssoftware, dass diese Ports nicht blockiert werden. Wie du das am besten machst, erfährst du durch eine Recherche auf Google.
