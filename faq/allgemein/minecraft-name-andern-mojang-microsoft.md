# Minecraft-Name ändern (Mojang/Microsoft)

Wenn du deinen Minecraft-Namen bei Mojang/Microsoft ändern willst, kannst du dies gerne jederzeit tun!

Alle deine Account-Informationen werden anhand der sogenannten **UUID** (Universally Unique Identifier / Global einzigartige ID) gespeichert. Dadurch ist eine Änderung des Anzeigenamens für deinen Account/Charakter überhaupt möglich.

{% hint style="danger" %}
Wichtig ist, dass du **nach** der Änderung deines Minecraft-Namens **mindestens einmal** neu auf GrieferGames joinst, damit der Server nachvollziehen kann, **dass** du eine Namensänderung vorgenommen hast und die Daten an deiner UUID neu sichert.
{% endhint %}
