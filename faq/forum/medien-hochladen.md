# Medien hochladen

### Bilder

Du kannst Bilder in deinen Beiträgen hochladen, indem du auf „Dateianhänge“ klickst, danach auf „Hochladen“. Jetzt suchst du die Datei auf dem eigenen Computer und wählst "Öffnen".

Wenn du das getan hast und die Datei bei „Dateianhänge“ aufgelistet wird, kannst du diese nun als kleinere Version im Text einbinden, indem du auf „Vorschau einfügen“ gehst. Du hast zudem auch die Möglichkeit, das originale Bild zu präsentieren. Klicke hierzu auf „Original einfügen“.

{% hint style="warning" %}
Das Verlinken oder Einfügen von Bildern externer Webseiten ist aus rechtlichen & sicherheitsrelevanten Gründen blockiert und wird automatisch durch einen Vermerk und eine Direktverlinkung zur Zielseite ersetzt.
{% endhint %}

{% hint style="info" %}
Für das Einfügen von Bildern liegen gewisse Einschränkungen vor. Beachte bitte die Angaben zur Dateigröße, unterstützten Dateiformaten und der Bildauflösung.
{% endhint %}

### Videos

Wenn du Videos hochladen willst, kannst du dies gerne über [YouTube](https://www.youtube.com/) oder [Twitch](https://twitch.tv/) machen. Den Link zum entsprechenden Video kannst du dann einfach in das Textfeld vom neuen Thema eintragen. Die Software bettet das Video automatisch als Player-Inhalt für dich ein.

{% hint style="info" %}
Beachte, dass zur Anzeige im Beitrag der Zugriff auf die Datei gegeben sein muss.&#x20;

* Bei YouTube muss das Video als "Öffentlich" oder "Nicht Gelistet" hochgeladen sein.
* Auf Twitch muss der VOD-Inhalt ohne "Folgen" oder "Abonnement"zur Verfügung stehen.
{% endhint %}
