# Rang-Befehle

{% tabs %}
{% tab title="Premium" %}


| Befehl     | Funktion                            |
| ---------- | ----------------------------------- |
| /msgtoggle | MSG-Nachrichten zulassen/blockieren |
| /d chicken | In ein Huhn verwandeln              |
| /ud        | Verwandlung aufheben                |
{% endtab %}

{% tab title="Ultra" %}


| Befehl                 | Funktion                                                |
| ---------------------- | ------------------------------------------------------- |
| /hat                   | Item, welches man in der Hand hält, auf den Kopf setzen |
| /hat off               | Item vom Kopf lösen                                     |
| /nick \[Nickname]      | Angezeigten In-Game-Name ändern                         |
| /nick off              | Nickname entfernen                                      |
| /tptoggle              | Teleportationsanfragen zulassen/blockieren              |
| /schild                | Schilder bearbeiten                                     |
| /d cow, creeper, horse | In eine Kuh, einen Creeper, ein Pferd verwandeln        |
| /ud                    | Verwandlung aufheben                                    |
{% endtab %}

{% tab title="Legende" %}


| Befehl                                                                          | Funktion                                                                                                                                    |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| /p flag set notify-enter true/false                                             | Erhalte eine Nachricht wenn Spieler dein Grundstück betreten                                                                                |
| /p flag set notify-leave                                                        | Erhalte eine Nachricht wenn Spieler dein Grundstück verlassen                                                                               |
| /p flag set greeting \[Text]                                                    | Grußnachricht beim Betreten des Grundstücks anzeigen                                                                                        |
| /p flag set farewell \[Text]                                                    | Grußnachricht beim Verlassen des Grundstücks anzeigen                                                                                       |
| /p flag set music \[ID]                                                         | Musik auf dem Grundstück abspielen                                                                                                          |
| [/pholo](spezielle-features/hologramme.md)                                      | Hologramm verwalten                                                                                                                         |
| /trails                                                                         | Im Hub das Effekt-Menü aufrufen                                                                                                             |
| /d guardian, enderman, endermite, iron\_golem, magma\_cube, ocelot, pig, rabbit | In einen Wächter, einen Enderman, eine Endermite, einen Eisengolem, einen Magmaschleim, einen Ozelot, ein Schwein, ein Kaninchen verwandeln |
| /ud                                                                             | Verwandlung aufheben                                                                                                                        |
{% endtab %}

{% endtab %}
