# Grundstücks-Informationen

<table><thead><tr><th width="132" align="center">Funktion</th><th>Beschreibung</th></tr></thead><tbody><tr><td align="center">ID</td><td>Die ID des Grundstücks, auf welchem man sich befindet, ist wie die UUID des Minecraft-Accounts eindeutig. Sie bleibt immer gleich, egal was man macht.</td></tr><tr><td align="center">Alias</td><td>Der „Spitzname“ des Grundstücks, auf welchem man sich befindet. Wenn man <code>/p set alias</code> eingibt, kann man mit <code>/p h</code> zum eigenem Grundstück kommen. Der Spitzname wird also geändert.<br></td></tr><tr><td align="center">Besitzer</td><td>Zeigt den aktuellen Besitzer an.</td></tr><tr><td align="center">Biom</td><td>Zeigt das aktuelle Biom des Grundstücks an. Das Biom kann mit <code>/p biome</code> geändert werden.</td></tr><tr><td align="center">Baurechte</td><td>Zeigt an, ob man auf dem Grundstück, auf dem man sich gerade befindet, Blöcke setzen und abbauen kann.</td></tr><tr><td align="center">Wertung</td><td>Zeigt die Bewertung des Grundstücks an. Dieses Feature gibt es auf GrieferGames nicht.</td></tr><tr><td align="center">Helfer</td><td>Hier werden Leute angezeigt, die man mit <code>/p add</code> hinzugefügt hat. Sie haben erst dann Baurechte auf dem Grundstück, wenn der Grundstücksbesitzer auf dem Citybuild-Server online ist.</td></tr><tr><td align="center">Vertraut</td><td>Hier werden Leute angezeigt, die man mit <code>/p trust</code> hinzugefügt hat. Sie haben immer Baurechte.</td></tr><tr><td align="center">Verboten</td><td>Hier werden Leute angezeigt, die man mit <code>/p deny</code> vom Grundstück verboten hat. Sie haben keine Erlaubnis mehr, das Grundstück zu betreten.</td></tr><tr><td align="center">Flags</td><td>Bei dieser Option werden alle hinzugefügten Flags auf dem Grundstück angezeigt. Mehr Informationen zu den <a href="grundstuecks-flags.md">Grundstücks-Flags</a>.</td></tr></tbody></table>
