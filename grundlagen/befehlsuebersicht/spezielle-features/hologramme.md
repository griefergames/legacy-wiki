# Hologramme

| Befehl             | Funktion                                                |
| ------------------ | ------------------------------------------------------- |
| /pholo             | Listet alle Hologramm-Befehle auf                       |
| /pholo list        | Zeigt alle Hologramme des jeweiligen Servers            |
| /pholo cr          | Erzeugt ein Hologramm                                   |
| /pholo rm          | Löscht ein Hologramm                                    |
| /pholo add         | Fügt eine neue Zeile zum Hologramm hinzu                |
| /pholo edit        | Ändert eine Zeile in einem Hologramm                    |
| /pholo mv          | Verschiebt das Hologramm auf die aktuelle Position      |
| /pholo tp {Nummer} | Teleportiere dich zum Hologramm mit der Hologrammnummer |
| /pholo removeplot  | Entfernt alle Hologramme auf dem Grundstück             |
