# Clan-System

Folgende Befehle kannst du für das [Clan-System](../../../erweiterte-features/das-clan-system.md) verwenden.

| Befehl                     | Funktion                                                                                           |
| -------------------------- | -------------------------------------------------------------------------------------------------- |
| /clan                      | Listet alle Clan-Befehle auf                                                                       |
| /clan create  {Name} {Tag} | Erstellt einen Clan mit Namen und Tag                                                              |
| /clan settag {Tag}         | Setzt den Clan-Tag neu                                                                             |
| /clan setname {Name}       | Setzt den Clan-Namen neu                                                                           |
| /clan setcb {Angabe}       | Legt den Haupt-Citybuild-Server des Clans fest                                                     |
| /clan setleader {Spieler}  | Setzt ein Clan-Mitglied/-Moderator als  Eigentümer                                                 |
| /clan uprank {Name}        | <p>Befördert ein Clan-Mitglied zum Moderator<br>(kann Mitglieder &#x26; Einladungen verwalten)</p> |
| /clan derank {Name}        | Degradiert einen Clan-Moderator zum Mitglied                                                       |
| /clan invite {Spieler}     | Lädt einen Spieler zum Clan ein                                                                    |
| /clan revoke {Spieler}     | Offene Einladung eines Spielers zurückziehen                                                       |
| /clan invites              | Alle Einladungen des Clans auflisten                                                               |
| /clan list                 | Zeigt alle Clan-Informationen an                                                                   |
| /clan info {Name/Tag}      | Zeigt Clan-Informationen eines anderen Clan an                                                     |
| /clan maxmember            | Zeigt die maximale Anzahl an Clan-Mitgliedern an                                                   |
| /clan money                | Zeigt das Gesamtvermögen des Clans (Bank & Bargeld von jedem Mitglied summiert) an                 |
| /clan toplist              | Zeigt die Topliste der reichsten Clans an                                                          |
| /clan accept {Name}        | Nimmt eine Clan-Einladung an                                                                       |
| /clan reject {Name}        | Lehnt eine Clan-Einladung ab                                                                       |
| /clan kick {Spieler}       | Entfernt ein Mitglied aus dem Clan                                                                 |
| /clan leave                | Verlässt den Clan                                                                                  |
| /clan delete               | Löscht den Clan                                                                                    |
