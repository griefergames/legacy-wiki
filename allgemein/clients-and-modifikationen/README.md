# 🧩 Clients & Modifikationen

Auf GrieferGames kannst du auch mit Modifikationen spielen, solange diese dir keinen erheblichen Spielvorteil verschaffen. Maßgeblich ist hierfür das [Regelwerk](../regelwerk.md) (§ 2 Abs. 5 und Abs. 8).

In diesem Bereich findest du:

* [Empfohlene Modifikationen](empfohlene-modifikationen.md) – vom Team geprüfte Modifikationen für ein besseres Spielerlebnis
* [CustomBlocks](customblocks.md) – Installation unserer eigenen CustomBlocks-Mod
