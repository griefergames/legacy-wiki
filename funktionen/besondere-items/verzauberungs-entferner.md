# 📕 Verzauberungs-Entferner

Aus dem [CaseOpening](../features/das-case-opening.md) kann man ein Item namens „Verzauberung Entferner“ ziehen. Damit entfernst du eine einzelne Verzauberung von einem Item. Alle anderen Verzauberungen bleiben erhalten.

Das Gegenstück dazu ist das [Verzauberungs-Upgrade](verzauberungs-upgrade.md), mit dem du eine Verzauberung um eine Stufe erhöhst.

## Ablauf

Mache einen Rechtsklick mit dem Verzauberungs-Entferner. Danach läuft es folgendermaßen ab:

1. Wähle in deinem Inventar das Item aus, von dem du eine Verzauberung entfernen möchtest.
2. Wähle im Menü die Verzauberung aus, die entfernt werden soll.
3. Diese eine Verzauberung wird vom Item entfernt.

Der Verzauberungs-Entferner wird dabei verbraucht und verschwindet. Die benötigten Level zum Reparieren oder Umbenennen des Items bleiben gleich.

## Unterstützte Items

* Schwerter, Spitzhacken, Äxte, Schaufeln und Hacken
* Helme, Brustpanzer, Hosen und Stiefel aus Leder, Eisen, Gold und Diamant
* Bögen

{% hint style="warning" %}
Kettenrüstung, Angeln, Scheren und andere Items werden nicht unterstützt.
{% endhint %}
