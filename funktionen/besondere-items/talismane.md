# 🧿 Talismane

Talismane geben dir dauerhafte Vorteile, z. B. schnelleres Fliegen, Rabatte oder mehr Belohnungen. Du rüstest sie in deinem **Talisman-Menü** aus, und sie wirken, solange sie dort liegen.

Talismane kannst du unter anderem im [CaseOpening](../features/das-case-opening.md) gewinnen.

## Talismane ausrüsten

1. Öffne mit `/talisman` dein Talisman-Menü.
2. Klicke in deinem Inventar auf den Talisman, den du ausrüsten möchtest.
3. Der Talisman wandert auf einen freien Platz im Menü und wirkt ab sofort.

Um einen Talisman abzulegen, klickst du ihn im Menü an. Er landet dann wieder in deinem Inventar. Dafür brauchst du einen freien Platz im Inventar.

Deine ausgerüsteten Talismane bleiben gespeichert, auch wenn du den Server verlässt oder wechselst.

{% hint style="info" %}
Jede Talisman-Art kannst du nur **einmal** gleichzeitig ausrüsten. Einen zweiten Talisman für Fluggeschwindigkeit kannst du also nicht zusätzlich ausrüsten.
{% endhint %}

## Talisman-Plätze

Jeder Spieler kann mindestens **einen** Talisman ausrüsten. Mit weiteren freigeschalteten Plätzen trägst du bis zu **7** Talismane gleichzeitig.

Einen zusätzlichen Platz schaltest du mit dem Item **+1 /talisman-slot** frei, das du ebenfalls im CaseOpening gewinnen kannst:

1. Nimm das Item in die Hand und mache einen Rechtsklick.
2. Bestätige im Fenster „Item einlösen?“.
3. Das Item wird verbraucht und du hast einen Talisman-Platz mehr.

Hast du bereits alle Plätze freigeschaltet, kannst du das Item nicht mehr einlösen.

Sind alle deine Plätze belegt, musst du zuerst einen Talisman ablegen, bevor du einen neuen ausrüsten kannst.

## Übersicht der Talismane

Die Stufe steht im Namen des Talismans, z. B. „Admin-Shop-Rabatt Stufe 2“.

| Talisman | Wirkung |
| --- | --- |
| Fluggeschwindigkeit | Du fliegst schneller. Je höher die Stufe, desto schneller. |
| Laufgeschwindigkeit | Du läufst schneller. Je höher die Stufe, desto schneller. |
| Block-des-Tages-Boost | **5 %** mehr Geld und Kristalle pro Stufe bei den Belohnungen vom [Block des Tages](../features/der-block-des-tages.md). |
| Admin-Shop-Rabatt | **5 %** Rabatt pro Stufe im [Admin-Shop](../features/das-adventurer-system.md#der-admin-shop). |
| Adventurer-Boost | **10 %** mehr Adventurer-Coins pro Stufe für erledigte [Adventurer-Aufgaben](../features/das-adventurer-system.md). |
| Orb-Verkäufer-Rabatt | **5 %** Rabatt pro Stufe beim [Orb-Verkäufer](../features/das-orb-system.md#der-orb-verkaeufer-verkaeufer). |
| Zauberwald-Zeit | Einmal pro Tag zusätzliche Zeit im [Zauberwald](../features/der-zauberwald.md). Die Dauer steht auf dem Talisman, z. B. **15 Minuten**. |
| Instant Kill | Alle Wesen außer Spielern, z. B. Monster, Tiere und Dorfbewohner, tötest du mit einem Schlag. |
| Bonus Drop | Beim Abbauen in der Farmwelt und im Nether hast du eine Chance auf einen besonderen Bonus-Drop. Wie hoch sie ist, wird nicht angezeigt. Mit jeder Stufe steigt sie. |
| Orb-Angel Bonus | Höhere Chance, mit der Orb-Angel einen Schatz zu ziehen. |

{% hint style="info" %}
Die Zauberwald-Zeit bekommst du gutgeschrieben, sobald du den Talisman ausrüstest oder einen Server betrittst. Danach gibt es sie frühestens am nächsten Tag ab **4 Uhr** morgens wieder.
{% endhint %}

{% hint style="warning" %}
Mit „Instant Kill“ sterben auch deine eigenen Tiere und Dorfbewohner durch einen einzigen Schlag. Lege den Talisman vorher ab, wenn du sie behalten möchtest.
{% endhint %}
