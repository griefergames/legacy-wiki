# 🪄 Verzauberungs-Upgrade

Aus dem CaseOpening kann man ein Item namens „Verzauberungs-Upgrade“ ziehen. Damit kannst du eine einzelne Verzauberung auf einem Item um eine Stufe erhöhen. Das Upgrade funktioniert für alle Rüstungen, Werkzeuge, Bögen und Schwerter.

<div align="center"><figure><img src="../../.gitbook/assets/wnYfOiD.png" alt="Item-Beschreibung des Verzauberungs-Upgrades"><figcaption></figcaption></figure></div>

## Ablauf

Klicke das Verzauberungs-Upgrade an. Danach läuft es folgendermaßen ab:

1. Wähle das verzauberte Item aus, das du verbessern möchtest.
2. Wähle die Verzauberung aus, die gesteigert werden soll.
3. Diese eine Verzauberung wird dann um +1 gesteigert.

Das Verzauberungs-Upgrade wird dabei verbraucht und verschwindet. Es gibt keine Einschränkungen, welche Verzauberungen erhöht werden können. Die einzige Einschränkung ist, dass das Upgrade nur für Rüstungen, Werkzeuge, Bögen und Schwerter nutzbar ist.
