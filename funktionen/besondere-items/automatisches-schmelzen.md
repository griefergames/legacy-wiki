# 🔥 Automatisches Schmelzen

Werkzeuge mit **automatischem Schmelzen** brennen bestimmte Blöcke direkt beim Abbauen, so wie es ein Ofen tun würde. Du sparst dir den Weg zum Ofen und den Brennstoff.

## So funktioniert das Item

Baue mit dem Werkzeug ganz normal ab:

* Aus **Sand** wird **Glas**.
* Aus einem **Tonblock** wird **gebrannter Ton**.

## Farbe auswählen

Bei Werkzeugen mit Auswahl legst du selbst fest, welcher Block beim Abbauen droppt. So bekommst du z. B. direkt gefärbtes Glas.

1. Mache einen Rechtsklick mit dem Werkzeug in der Hand. Das Menü „Block auswählen“ öffnet sich.
2. Klicke auf „Sand“ oder „Clay“ (Tonblock).
3. Wähle aus, was beim Abbauen droppen soll.

Für Sand stehen Glas und gefärbtes Glas in allen **16** Farben zur Auswahl. Für Tonblöcke stehen gebrannter Ton und gefärbter Ton in allen **16** Farben zur Auswahl.

{% hint style="info" %}
Deine Auswahl wird auf dem Werkzeug gespeichert. Sie gilt, bis du sie im Menü wieder änderst.
{% endhint %}
