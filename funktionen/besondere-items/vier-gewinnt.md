# 🔴 4-Gewinnt

Mit dem **Mobilen 4-Gewinnt** stellst du dir einen Spieltisch auf dein Grundstück. Dort spielst du Vier gewinnt gegen andere Spieler, schaust fremden Partien zu und sammelst Punkte für die Rangliste.

Das Mobile 4-Gewinnt kannst du im [CaseOpening](../features/das-case-opening.md) gewinnen.

## So funktioniert das Item

1. Platziere das Mobile 4-Gewinnt auf deinem Grundstück.
2. Mache einen Rechtsklick auf den Block. Das Menü „Vier Gewinnt“ öffnet sich.

{% hint style="danger" %}
Baust du das Mobile 4-Gewinnt ab, wird es zerstört. Überlege dir den Platz also vorher gut.
{% endhint %}

Im Menü hast du folgende Möglichkeiten:

* **Spielen:** Du kommst in die Warteschlange dieses Spieltischs.
* **Zuschauen:** Du schaust einem laufenden Spiel zu.
* **Spielstein auswählen:** Du änderst das Aussehen deiner Spielsteine.
* **Statistik:** Du siehst deine Punkte, Siege und Niederlagen, die besten Spieler und deine letzten Spiele.

{% hint style="info" %}
Damit Besucher an deinem Spieltisch spielen können, gib 4-Gewinnt über die [„use“-Flag](../befehlsuebersicht/grundstuecks-befehle/grundstuecks-flags.md#use-flag) frei. Am einfachsten geht das im [Use-Flag-Menü](../grundstuecke/grundstueck-menue.md#use-flag-menue) des Grundstück-Menüs.
{% endhint %}

## Ein Spiel starten

1. Klicke im Menü auf „Spielen“. Du landest in der „Spielerauswahl“.
2. Dort siehst du die Köpfe aller Spieler, die an diesem Spieltisch warten.
3. Klicke auf den Kopf deines Wunschgegners. Er bekommt eine Nachricht, dass du gegen ihn spielen möchtest.
4. Klickt er auch auf deinen Kopf, beginnt das Spiel.

An einem Spieltisch können bis zu **8** Spieler gleichzeitig warten.

## Spielregeln

Ihr setzt abwechselnd einen Spielstein. Wer zuerst vier eigene Steine in einer Reihe hat, gewinnt.

Für jeden Zug hast du **30 Sekunden** Zeit. Zehn Sekunden vor Ablauf wirst du gewarnt.

{% hint style="warning" %}
Setzt du nicht rechtzeitig oder schließt du das Spielfenster, verlierst du das Spiel.
{% endhint %}

## Punkte und Statistik

Jeder Spieler startet mit **1.000** Punkten. Für einen Sieg bekommst du Punkte, für eine Niederlage verlierst du welche. Gewinnst du gegen einen stärkeren Gegner, gibt es mehr Punkte.

Die Rangliste in der Statistik wird alle **30 Minuten** aktualisiert.

## Spielsteine

Unter „Spielstein auswählen“ legst du fest, wie deine Steine aussehen. Welche Spielsteine dir zur Verfügung stehen, hängt von deinem [Rang](../befehlsuebersicht/rang-befehle.md) ab.
