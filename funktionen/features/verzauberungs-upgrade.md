# 🪄 Verzauberungs-Upgrade & Reparatur-Barren

## Verzauberungs-Upgrade

Aus dem CaseOpening kann man ein Items namens "Verzauberungs-Upgrade" ziehen. Dieses funktioniert für alle Rüstungen, Werkzeuge, Bögen und Schwerter.

<div align="center"><figure><img src="../../.gitbook/assets/wnYfOiD.png" alt="Bild"><figcaption>Erfolge auf dem 1.8 Netzwerk</figcaption></figure></div>

Der Ablauf ist Folgender:

- **Item auswählen, welches verzaubert ist**\
- **Die Verzauberung wählen, welche gesteigert werden soll**\
- **Diese eine Verzauberung wird dann um +1 gesteigert**\
Das Item wird dann entsprechend verbraucht und verschwindet. Es gibt keine Einschränkungen zu Verzauberungen, die erhöht werden können. Die einzige Einschränkung ist, dass es nur für alle möglichen Rüstungen, Werkzeuge, Bögen und Schwerter machbar ist. 

## Reparatur-Barren

Außerdem kann man aus dem CaseOpening ebenfalls ein Item namens "Reparatur-Barren" ziehen. Dieses funktioniert genau gleich und kann auch für alle Rüstungen, Werkzeuge, Bögen und Schwerter angewendet werden. Das jeweilige Item wird dadurch vollständig repariert.

<div align="center"><figure><img src="../../.gitbook/assets/bWltrqF.png" alt="Bild"><figcaption>Erfolge auf dem 1.8 Netzwerk</figcaption></figure></div>
Das Item wird dann entsprechend verbraucht und verschwindet. Die benötigten Level zum Reparieren/Umbenennen des Items und die NBT-Tags bleiben dadurch unberührt.
